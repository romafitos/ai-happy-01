# The Otter's Starfish

An otter floats on its back at golden sunset, laughing, holding one orange starfish up like a trophy — one otter, one starfish, one sunset.

## Run

```sh
mkdir -p output
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

The program copies `entry.png` into the output directory. The copy is byte-identical every run, so the output is fully deterministic.
